# 战术突击 · Tactical Assault

穿越火线（CrossFire）风格的浏览器第一人称射击游戏。原生 HTML + Three.js，**无构建步骤、无 npm 依赖**，打开网页即可玩。

**▶ 在线试玩：<https://tianlic2.github.io/cf-browser-game/>**

> 建议用桌面版 Chrome / Edge / Safari。进入战场后需要点击画面锁定鼠标指针（按 `Esc` 解锁）。

## 玩法

战场是 CF 经典「运输船」集装箱货轮的甲板（晴天白昼），团队竞技模式：**先到 40 击杀，或 10 分钟倒计时结束时比分领先**者胜。你从船尾（+z）出生，敌人从船头（-z）基地持续刷出。

- 首页是 CF 风格大厅，左侧四个页签：**开始游戏**（调**敌人数量 1~8** 与**难度 简单 / 普通 / 困难**）、**作战手册**（全部键位）、**武器库**（八件武器的出厂数值）、**个人仓库**（当前三个背包的配装）。后三页只读。对局中也能用 `+` / `-` 实时增减人数。
- 按住 `Tab` 看战绩面板（左右两列是我方·保卫者与敌方·潜伏者）。
- 被击杀后是 3 秒死亡视角（镜头会自动转向击杀者），然后在你方出生点复活并获得约 1.2 秒无敌。

## 操作

| 按键 | 动作 | 按键 | 动作 |
| --- | --- | --- | --- |
| `W` `A` `S` `D` | 移动（默认奔跑） | `R` | 换弹 |
| `Shift` | 静步潜行（无声） | `1` `2` `3` | 主武器 / 副武器 / 军刀 |
| `Ctrl` | 按住下蹲 | `4` | 投掷物循环（手雷 → 闪光弹 → 烟雾弹） |
| `Space` | 跳跃（支持连跳） | `Q` | 主/副武器快速切换 |
| 鼠标左键 | 开火 | `G` | 丢弃手上的主武器 / 副武器 |
| 鼠标右键 / `V` | 开镜（仅 AWM，两级变倍）；手上有军刀时是**重击** | `B` | 背包面板 |
| `+` / `-` | 增减敌人数量 | `Tab` | 战绩面板 |
| `[` / `]` | 换皮肤（需先按 `B` 开面板） | `Enter` | 聊天发言 |
| `Esc` | 解锁鼠标 | | |

背包切换按 CF 原版规则限制：**只能在出生点安全区内、且本回合尚未开火时**切换（按 `B` 后再按 `1/2/3` 选第几个背包）。

换皮肤**没有这层限制**——按 `B` 开面板后 `[` / `]` 循环当前背包主武器的皮肤，只要活着就能换（纯外观，不影响平衡）。面板里的选择**跨局保留**（下一局还是它），与捡来的枪不同。

军刀有轻重两档：**左键轻击**（40 伤害，0.4 秒一刀），**右键重击**（65 伤害，1 秒一刀）。从背后捅是**背刺**，伤害翻倍（轻 90 / 重 180）——除了爆头，这是唯一能一刀带走满血敌人的方式。

### 聊天

左下角的聊天框与 CF 同位置。**按 `Enter` 打字，再按 `Enter` 发出**（`Esc`解锁鼠标会顺带取消输入）。

打字期间**不会**释放鼠标指针——视角定住、游戏照常跑（也就是说打字的时候真的会被打死）。此时除了输入框，所有按键都不再驱动游戏：`G` 不掉枪、`1/2/3` 不切枪、`R` 不换弹、`+`/`-` 不改人数、`B` 不开背包、`Tab` 不跳焦点。

**线里不是只有你。** 潜伏者会盯着战况说话——你爆头、连杀、被反杀，都有人点评；你打得狠了他们互相提醒「都给我压住」，你也被打死时击杀者会说一句。你发的消息他们会接：问句、挑衅、普通聊天走的是不同的回答口径（只做关键词粗分流，别指望他们真读懂）。冷场的时候也会有人自己找话说。

### 掉落与捡枪

- 每个敌人**随机携带** AK-47 / M4A1 / AWM 三把主武器之一，连同随机皮肤（共 11 种组合），倒地时枪就掉在它倒下的位置。
- 按 `G` 丢下自己的主武器或副武器；**只有对应槽位空着时才会捡起地上那把枪**——手上已经有枪的话，从上面走过去什么也不会发生。想换枪就先丢再捡。
- 捡到的枪（含皮肤）会**一直用到本局结束**（复活拿回来的也是它）；重开一局才恢复成背包里配好的那把。

## 特性

- **多武器系统**：AK-47 / M4A1 / AWM / USP / 军刀 / 手雷·闪光弹·烟雾弹三件套，各有独立弹道、射速、后坐与伤害（AK 三枪死、AWM 一枪毙命、爆头一律秒杀）。
- **CS 口径的枪感**：每把枪有一张**逐发弹道表**——连发时枪口沿着固定的轨迹往上爬再左右摆（AK 的 30 发表取自 CS2），停火后按指数 + 线性恢复。后坐**相机全程跟随**，所以你看到的抬枪就是子弹真实的落点，压枪练得出来。
- **第一人称双手**：一双真正握住枪的手（手枪/步枪/狙击/军刀/投掷物各一套握姿），不是悬空的模型；换弹时左手会离开护木去腰袋掏弹匣、插进弹匣井、拍实再归位。
- **AWM 两级变倍开镜**，开火强制退镜并**拉栓 1.2 秒**（栓动期间不能开火、不能重新开镜），带呼吸晃动。
- **程序化士兵骨架**：敌人的走位、据枪、点射、受击、倒地全部是程序化驱动的关节动画（不是静态模型平移），手臂用两骨 IK 按在枪上。敌人 AI 有惯性移动、转身角速度、视线遮挡判定与障碍绕行。
- **敌人随机配装 + 掉落捡枪**：敌人端的是真枪（不是贴图），型号与皮肤每局随机；击杀后枪掉在原地可以捡起来用，自己也能按 `G` 丢枪换枪。
- **武器皮肤就是「换整把模型」**：8 款模型皮肤（AK 老兵 / M4 雷神·霜白·泡泡糖·黄金M4·炫金 / AWM 紫电·荒原）各自自带一份高精度 GLB，按 `B` 开面板后用 `[` / `]` 换，**首次选中才下载对应模型**。每把枪另有「原厂」一项（不上漆，用基础低模）。敌人与地面掉落物永远用基础低模 + 该款皮肤的分部位配色。
- **双通道视模渲染**：武器与手臂在独立场景里二次绘制，永远不会插进集装箱，开镜时自动隐藏。
- **左上角小地图**（CF 同款雷达）：运输船俯视轮廓 + 集装箱/甲板室/栈桥，标出你自己的位置与朝向。敌人**只在「你看得见」或「正在交火」时显形**（视野锥 + 真实视线遮挡，枪口火光会短暂暴露位置）——这是雷达，不是透视挂。
- **CF 式切枪动作**：换枪是一段**收枪 → 出枪**的动作（狙击出枪还要拉栓），**出枪期间不能开火**。逻辑上仍然即时——弹药 HUD、退镜都在切的那一帧就变了，只是屏幕上那把枪要举起来。
- **击杀图标化**：屏幕中心是**武器剪影**而非文字，爆头叠爆头徽记、满血爆头升级成**黄金爆头**；右上击杀信息条同步改成 `[击杀者] [武器图标] [武器名] [爆头徽记] [被击杀者]`。
- **模拟聊天系统**：潜伏者会按你的战绩实时评论（爆头 / 连杀 / 阵亡 / 捡枪各有各的说法），你按 `Enter` 发言他们还会接话；同屏 6 行、每条约 9 秒淡出，与 CF 的左下角位置一致。
- **程序化音效**：枪声、换弹、脚步、爆炸、闪光耳鸣、连杀播报全部由 Web Audio 实时合成，无音频素材文件。
- **程序化贴图**：天空/海浪/集装箱瓦楞/木箱板条，以及每发随机形状的星芒枪口火光。

## 本地运行

需要任意静态服务器（ES Module 与 GLB 不能用 `file://` 打开）：

```bash
python3 -m http.server 8000
# 然后打开 http://localhost:8000/
```

`?debug` 会在 `window.__tactical` 上挂一组调试钩子（切枪、冻结敌人、定格换弹姿势、读取画面状态等）。

## 技术说明

- Three.js 固定在 `0.160.0`，**已本地化到 `vendor/three/`**，由 `index.html` 的 import map 指向本地，不依赖任何 CDN。
- 武器手感（逐发弹道表、恢复曲线、开镜倍率与灵敏度、刀的轻重击）与第一人称的双手几何移植自
  [counter-strike-in-browser](https://github.com/StarKnightt/counter-strike-in-browser)（MIT License，Copyright (c) 2026 StarKnightt），
  只用了它的数值与 `models/cs/ak47.glb` 里的四个手/袖节点；枪械模型、皮肤、地图、敌人、音效均为本项目自有。
- 所有资源路径都是**相对文档**的（`./…`），因此既能本地跑，也能作为 GitHub Pages 的**项目页**（站点根在 `/<仓库名>/`）跑。
- 材质与几何为程序化生成或本地 GLB，无外部资源依赖。
- 更多实现细节与踩过的坑见 [`AGENTS.md`](AGENTS.md)，视觉规范见 [`DESIGN.md`](DESIGN.md)。
