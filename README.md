# 战术突击 · Tactical Assault

穿越火线（CrossFire）风格的浏览器第一人称射击游戏。原生 HTML + Three.js，**无构建步骤、无 npm 依赖**，打开网页即可玩。

**▶ 在线试玩：<https://tianlic2.github.io/cf-browser-game/>**

> 建议用桌面版 Chrome / Edge / Safari。进入战场后需要点击画面锁定鼠标指针（按 `Esc` 解锁）。

## 玩法

战场是 CF 经典「运输船」集装箱货轮的甲板（晴天白昼），团队竞技模式：**先到 40 击杀，或 10 分钟倒计时结束时比分领先**者胜。你从船尾（+z）出生，敌人从船头（-z）基地持续刷出。

- 首页是 CF 风格大厅，左侧四个页签：**开始游戏**（调**敌人数量 1~8** 与**难度 简单 / 普通 / 困难**）、**作战手册**（全部键位）、**武器库**（八件武器的出厂数值）、**个人仓库**（当前三个背包的配装）。后三页只读。对局中也能用 `+` / `-` 实时增减人数。
- 按住 `Tab` 看战绩面板（左右两列是我方·保卫者与敌方·潜伏者）。
- 被击杀后是 3 秒死亡视角（镜头会自动转向击杀者），然后在你方出生点复活并获得约 1.2 秒无敌。

## 操作

| 按键 | 动作 | 按键 | 动作 |
| --- | --- | --- | --- |
| `W` `A` `S` `D` | 移动（默认奔跑） | `R` | 换弹 |
| `Shift` | 静步潜行（无声） | `1` `2` `3` | 主武器 / 副武器 / 军刀 |
| `Ctrl` | 按住下蹲 | `4` | 投掷物循环（手雷 → 闪光弹 → 烟雾弹） |
| `Space` | 跳跃（支持连跳） | `Q` | 主/副武器快速切换 |
| 鼠标左键 | 开火；投掷物按住拉环、松开投出 | `G` | 丢弃手上的主武器 / 副武器 |
| 鼠标右键 / `V` | 开镜（仅 AWM，两级变倍）；手上有军刀时是**重击** | `B` | 背包面板 |
| `+` / `-` | 增减敌人数量 | `Tab` | 战绩面板 |
| `Enter` | 聊天发言 | `Esc` | 解锁鼠标 |

背包切换按 CF 原版规则限制：**只能在出生点安全区内、且本回合尚未开火时**切换——按 `B` 翻开背包面板，再按 `1/2/3` 选第几个背包，**选完自动收起面板**（被规则拦下时面板保持打开并给出原因）。

投掷物每条命各一颗：按住左键完成拉环后可以待投，松开甩出，离手才开始引信，随后切回之前的武器。切枪、聊天、失焦会取消未出手的投掷。手雷支持墙面/箱顶反弹、空中爆炸和掩体遮挡；闪光根据视线与朝向生效，烟雾逐渐扩散后消散。物理、伤害、引信和烟雾时长为本项目近似标定。

所有武器统一使用 AK 素材的蓝袖、黑色全指手套；AK 与三类投掷物保留素材中的骨骼动作，其他武器沿用各自握点、换弹和近战动作。

军刀左键单击横划，按住会接前刺；右键翻腕下刺。轻刀身体 35、头部 90，重刀身体 90、头部 180；每刀有前摇、有效命中窗口和收刀，不能隔墙命中。刀距按当前场景标定为 **1.4 米**（到实际命中表面），属于近似还原参数，不是官方精确数值。

### 聊天

左下角的聊天框与 CF 同位置。**按 `Enter` 打字，再按 `Enter` 发出**（`Esc`解锁鼠标会顺带取消输入）。

打字期间**不会**释放鼠标指针——视角定住、游戏照常跑（也就是说打字的时候真的会被打死）。此时除了输入框，所有按键都不再驱动游戏：`G` 不掉枪、`1/2/3` 不切枪、`R` 不换弹、`+`/`-` 不改人数、`B` 不开背包、`Tab` 不跳焦点。

**线里不是只有你。** 潜伏者会盯着战况说话——你爆头、连杀、被反杀，都有人点评；你打得狠了他们互相提醒「都给我压住」，你也被打死时击杀者会说一句。你发的消息他们会接：问句、挑衅、普通聊天走的是不同的回答口径（只做关键词粗分流，别指望他们真读懂）。冷场的时候也会有人自己找话说。

### 掉落与捡枪

- 每个敌人**随机携带** AK-47 / M4A1 / AWM 三把主武器之一，统一使用经典配色（木托 AK、黑色 M4、军绿 AWM），倒地时枪就掉在它倒下的位置。
- 按 `G` 丢下自己的主武器或副武器；**只有对应槽位空着时才会捡起地上那把枪**——手上已经有枪的话，从上面走过去什么也不会发生。想换枪就先丢再捡。
- 捡到的枪（含皮肤）会**一直用到本局结束**（复活拿回来的也是它）；重开一局才恢复成背包里配好的那把。

## 特性

- **多武器系统**：AK-47 / M4A1 / AWM / USP / 军刀 / 手雷·闪光弹·烟雾弹三件套，各有独立弹道、射速、后坐与伤害（AK 三枪死、AWM 一枪毙命、枪械爆头一击击杀）。
- **CS 口径的枪感**：每把枪有一张**逐发弹道表**——连发时枪口沿着固定的轨迹往上爬再左右摆（AK 的 30 发表取自 CS2），停火后按指数 + 线性恢复。后坐**相机全程跟随**，所以你看到的抬枪就是子弹真实的落点，压枪练得出来。
- **第一人称持枪**：经典 AK 使用 CF 社区包内的 51 骨骼手臂、枪械和 idle/reload/fire 动作，手指与枪一起运动；原换弹声音按动作事件对齐。M4/AWM 分别标定持枪构图，其他武器仍由既有手臂 IK 驱动。
- **AWM 两级变倍开镜**，开火强制退镜并**拉栓 1.2 秒**（栓动期间不能开火、不能重新开镜），带呼吸晃动。
- **经典 SWAT 人物**：社区 CF SWAT Reborn 模型、原贴图与 50 根骨骼，行走/据枪/受击/倒地由本项目 IK 驱动；头部直接按蒙皮网格判定爆头。AI 使用基于地图凸体碰撞的共享寻路流场。
- **敌人随机配装 + 掉落捡枪**：敌人端的是真枪（不是贴图），型号随机，默认采用经典配色；击杀后枪掉在原地可以捡起来用，自己也能按 `G` 丢枪换枪。
- **武器皮肤就是「换整把模型」**：10 款模型配装（AK 经典 / M4 雷神·霜白·泡泡糖·黄金M4·炫金 / AWM 紫电·荒原，另有黑色 M4 与军绿 AWM 经典配装）各自自带一份高精度 GLB，默认三把启动时加载，其余首次用到时加载。每把枪另有「原厂」一项（不上漆，用基础低模）。皮肤在**进入战场前就配好了**（默认对局的敌人掉落也采用经典配色），游戏里没有换皮肤的入口——三个背包的默认主武器分别是木托 AK / 黑色 M4 / 军绿 AWM，三把均使用精细模型。默认经典枪械在玩家、敌人与地面掉落物之间使用同一模型；其余未预加载皮肤可回退基础模型配色。
- **双通道视模渲染**：武器与手臂在独立场景里二次绘制，永远不会插进集装箱，开镜时自动隐藏。
- **左上角小地图**（CF 同款雷达）：圆形雷达内按等比例绘制运输船轮廓与集装箱/甲板室，标出你自己的位置与朝向。敌人**只在「你看得见」或「正在交火」时显形**（视野锥 + 真实视线遮挡，枪口火光会短暂暴露位置）——这是雷达，不是透视挂。
- **CF 式切枪动作**：换枪是一段**收枪 → 出枪**的动作（狙击出枪还要拉栓），**出枪期间不能开火**。逻辑上仍然即时——弹药 HUD、退镜都在切的那一帧就变了，只是屏幕上那把枪要举起来。
- **经典击杀军徽**：准星下方弹出金属羽翼军徽，普通击杀显示武器图形、爆头显示骷髅与瞄准刻线、满血爆头为金色。短促弹入、停留、淡出；英文连杀文字和原版男声同步。没有全屏冲击波或紫色边缘辉光。军徽为自行绘制的 SVG，黄金爆头仍沿用本作判定。
- **模拟聊天系统**：潜伏者会按你的战绩实时评论（爆头 / 连杀 / 阵亡 / 捡枪各有各的说法），你按 `Enter` 发言他们还会接话；同屏 6 行、每条约 9 秒淡出，与 CF 的左下角位置一致。
- **采样 + 合成的混合音效**：玩家 AK 使用 CF 社区移植包中的原开火、退匣、插匣、拉栓 WAV，保持原速。其他枪械、脚步和界面声音主要来自已有 CC0 录音，奖励音调等由 Web Audio 合成；大厅音乐由用户提供。各来源分别记录在 `audio/CREDITS.txt`，不能统称 CC0。
- **CF 经典英文连杀人声**：采用保卫者（Global Risk）七档录音：Double Kill → Multi Kill → Ultra Kill → Unbreakable → Unbelievable → You Want a Piece of Me? → Come and Get Some!。原速播放，快速连杀只保留最新一档；八杀以上复用最高档语音，HUD 继续累计。移除了系统朗读与电子连杀音阶。语音来源与权利归属单列在 `audio/CREDITS.txt`，不属于 CC0 音效。
- **经典地图素材**：运输船使用社区移植的原地图几何、贴图、烘焙光照与天空盒，保留原出生点和凸体碰撞；海面与枪口火光仍由本项目生成。

## 经典版视觉

当前已接入社区移植的 CF 运输船、SWAT Reborn、经典 AK-47 及四段 AK 原声。地图与人物加载失败时回退程序化实现。M4/AWM 仍为既有模型的经典配色，经典 AK 第一人称使用导入动作，其他双手与敌人人物动作使用本项目 IK，击杀军徽为自绘，枪感与 AI 也不是原客户端实现，因此并非完整 1:1 复刻。素材署名、转换方式与使用限制见 [经典素材说明](assets/classic/CREDITS.md)；本次改动在本地验证后已上线，在线版本即为此。

## 本地运行

需要任意静态服务器（ES Module 与 GLB 不能用 `file://` 打开）：

```bash
python3 -m http.server 8000
# 然后打开 http://localhost:8000/
```

`?debug` 会在 `window.__tactical` 上挂一组调试钩子（切枪、冻结敌人、定格换弹姿势、读取画面状态等）。

## 技术说明

- Three.js 固定在 `0.160.0`，**已本地化到 `vendor/three/`**，由 `index.html` 的 import map 指向本地，不依赖任何 CDN。
- 武器手感（逐发弹道表、恢复曲线、开镜倍率与灵敏度、刀的轻重击）移植自
  [counter-strike-in-browser](https://github.com/StarKnightt/counter-strike-in-browser)（MIT License，Copyright (c) 2026 StarKnightt），
  使用其数值和部分既有资产；新增 CF 社区素材的权利归属单列，不能视为本项目自有。
- **音效素材**：除 CF AK 与连杀语音外，既有枪声/换弹/脚步等录音取自该参考项目收录的 CC0 录音（Freesound）；
  收枪/出枪、空枪干击、开镜/退镜与页面交互声是我们自己从 Freesound 的 CC0
  录音里剪的（**Kenney UI Audio 已整体下线，一声都不剩**）；大厅背景音乐为用户提供的素材。
  逐文件署名见 [`audio/CREDITS.txt`](audio/CREDITS.txt)。
- 所有资源路径都是**相对文档**的（`./…`），因此既能本地跑，也能作为 GitHub Pages 的**项目页**（站点根在 `/<仓库名>/`）跑。
- 材质与几何为程序化生成或本地 GLB，无外部资源依赖。
- 更多实现细节与踩过的坑见 [`AGENTS.md`](AGENTS.md)，视觉规范见 [`DESIGN.md`](DESIGN.md)。
