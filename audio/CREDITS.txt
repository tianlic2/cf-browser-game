音频素材署名 / Audio asset credits
=================================

本目录的素材按来源分别列示。Freesound 录音适用所列 CC0；用户提供的大厅音乐与第四节 CF 游戏语音、第五节 CF AK 音效不据此宣称 CC0 或商用授权。

除第五节保留原 WAV 外，已有转码文件都是**单声道**（除 lobby_theme 为立体声），每个 stem 出两份：
  <stem>.ogg  —— Ogg Vorbis。Chrome / Firefox / Edge 走这一份。
  <stem>.m4a  —— MP4 容器 + AAC。Safari 走这一份（Chrome/Firefox 也认）。
  **ui/ 与 sw/ 下的 14 个 stem 只有 .m4a**：本机没有 Vorbis 编码器（macOS 的
  afconvert 只写 m4af / WAVE / AIFF / CAF / ADTS），这些不是从参考项目搬来的
  ogg，而是我们自己从 wav 编的。加载器对它们直接走第二个候选，不产生 404
  （见 scripts/audio.js 的 M4A_ONLY，按**stem 路径**列）。
**例外是两件用户提供的原始素材**：`impacts/headshot_kill.mp3`（第六节）与
`vo/fireinthehole.wav`（第七节）。两者都是**原样入库、未转码**，所以在 `SAMPLES` 里写成
自带扩展名的 stem —— 加载器那条「自带扩展名就原样用」的分支（同一个分支也在给
`classic/*.wav` 用）只请求这一个 URL，不产生 404。

二、UI / 手上动作（真实录音，Freesound CC0）
------------------------------------------------------------
**这一节整体替换掉了旧的 Kenney UI Audio 合成 blip**（原来那四个 ui_* 是 35~68 ms
的方波扫频，用户的反馈是"偏卡通"）。现在同一条分界线上的一切——按钮、页签、面板
开合、切枪收/出、空枪干击、开镜退镜——都是真实录音，音色靠**谱心**分开：
大按键脆 6.4k / 页签亮 6.1k / 开面板 5.6k / 关面板钝 3.1k；长枪出 5.2k、收 2.6k；

rate** 给，不烘进文件。

七、投掷物出手台词「Fire in the hole!」（用户提供）
------------------------------------------------------------
vo/fireinthehole.wav         <- 用户提供的 fireinthehole.wav（原在仓库根，已移入 audio/vo/）

**来源与许可未考证** —— 与第六节同一情形：文件由用户直接加入仓库，出处与授权均未提供。
因此**不能**与第一、二节的 CC0 素材混为一谈，也不据此宣称任何许可。

它是**用户提供的原始 WAV 原样入库、未转码**：2 ch / 44100 Hz / Int16 PCM / 85248 帧 /
约 1.933 s / 341036 字节（无任何元数据块）。在 scripts/audio.js 的 SAMPLES 里写成
**自带扩展名的 stem**（`vo/fireinthehole.wav`），加载器那条「自带扩展名就原样用」的分支
只请求这一个 URL（不带 .ogg/.m4a 两个候选、不产生 404），也因此不进 M4A_ONLY。

⚠️ **为什么另开 `vo/` 这一层目录，而不放进 `announcer/`**：两者都是人声，但**角色与路由
都不同**，放一起会让目录名撒谎。`announcer/`（第四节的 cf_gr_*）是**比赛播报人声**，播放时
传 `hudBus: true`，刻意绕开距离衰减、闪光弹低通与货舱混响；这一条是**玩家自己的台词**，
`fireInTheHole()` 不带 x/y/z、走 `master` + 混响（`wet` 0.2），与 `hurt()` 同一条路由 ——
它发生在世界里，被闪光弹闷住才是对的。

用途：**丢出手雷那一帧**播放（`main.js` 的 `throwGrenade()`，也就是实体真正建出来、
`updateGrenadeAction()` 判到 `a.t >= a.releaseAt` 的那一帧）。**不是拉环那一下**
（那是 `grenadePin()` / `cf_grenade_pin`，更早）。
**只有手雷（frag）喊**：调用点的判据是 `def.nade === "frag"`，它同时是 `updateGrenades()`
里 `g.kind === "frag"` 分流爆炸的那个字段。**闪光弹与烟雾弹的出手不喊这一声**，目前只有
同帧的甩手 whoosh —— 那是给它们各自补素材留的挂点，不是漏了。
**这一声没有合成兜底**（人声合不出来，同 `streak()` 那条线）：素材缺失或还没加载完时它
静默缺省，而**甩手那一声 whoosh 是同帧的另一个方法（`sfx.throwGrenade()`，注意它与
`main.js` 里那个同名函数是两回事），照常响** —— 三种投掷物都有。

实测（无头 Chrome + 真实投掷路径，见 AGENTS.md 本节）：手雷出手帧 i=50 / t=0.85 上
`thrown`、手雷计数减一、投掷物入池三件事同帧发生，该帧 lastAttempt 为
`{method:"fireInTheHole", id:"fireinthehole", reason:"sample"}`；拉环在 i=17 / t=0.30
（`cf_grenade_pin`）；闪光/烟雾同一次投掷里同样三标记同帧，但整段序列
`["grenadePin","throwGrenade","holster"]` 中不含 `fireInTheHole`。
**听感（够不够劲）未经人耳确认。**
