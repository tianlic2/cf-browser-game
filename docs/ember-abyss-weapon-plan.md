# 烬渊·镇魂：武器制作与验收计划

## 目标与范围

先做团队竞技用的独立第一人称步枪预览，确认质量后再接入正式游戏；生化大弹鼓形态放在后续阶段。武器、手套和袖口需风格统一，不能用未匹配的旧枪手臂拼接冒充完整资源。

## 设计基准

- 黑曜石黑和深枪灰金属为主体，暗金机械边缘，暗红能量纹；觉醒时逐渐转为红金。
- 造型应保留可辨认的握把、扳机护圈、枪托、弹匣、枪口和瞄具；第一人称枪身不能遮挡准心。
- 手部采用配套战术手套和袖口，双手握点及手指与枪身一致；弹匣、拉机柄等运动部件独立。
- 默认 40/120 发，初始射速 750–800 发/分钟；伤害、散布、穿透及移动速度以与现有武器实测比较后决定。
- 连杀可激活短时觉醒，提供清晰的枪身动画和有限的操控增益；不得自动瞄准或透视。

## 阶段

1. **设计与资源方案**：制作并核对多视角造型，明确同源手部、骨骼、动画及音频来源和使用条件。
2. **独立预览**：导入枪身、匹配手部与贴图；检查尺寸、握姿、光照、手指蒙皮和第一人称遮挡。
3. **动作**：完成待机、切枪、开火、完整换弹、检视和动作中断；检查弹匣和双手的接触与衔接。
4. **声音和特效**：配套开火、切枪、弹匣及闭锁声，按动作事件触发；加入枪口焰、曳光、觉醒及击杀反馈。
5. **预览验收**：在真实浏览器逐项检查模型、动作、音画同步、加载失败及运行性能，保留预览供用户检查。
6. **正式接入**：预览确认后配置背包、弹药、伤害、移动速度和第三人称掉落模型，回归其他武器和团队竞技。
7. **生化形态**：在已确认的设计上制作大弹鼓和独立平衡，测试僵尸击退、伤害反馈及性能。

## 硬性验收

- 视模提供完整配套手部和手指；待机、出枪、开火和完整换弹都真实可播放，音效与动作同步。
- 预览须能重播、暂停并检查每个动作；切枪或换弹中断时不得播放已取消动作的声音。
- 觉醒特效不得遮住准心；所有资源须明确来源及可用范围，不能在未经确认的情况下公开分发。
- 模型生成或动画工具返回成功不等于质量通过；缺少动作、音频或素材授权时保持预览状态并如实说明。
