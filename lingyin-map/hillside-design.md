# 灵隐寺山脊扩展

玩家体验：从山门后的登山石径上到西北山脊，在可防守的高点俯瞰寺院；攀登过程依次经过近距离竹林、山腰转角和开阔观景台。主动作仍是移动、跳跃和射击；路线宽度、护栏和转角控制暴露时间，山腰小平台可短暂停留，山顶有低矮掩体但不能靠一堵空气墙挡住射线。

对局循环：玩家为争取高处视野而离开庭院，沿有掩护的山路推进，同时承受狭路遭遇与被寺院发现的风险；成功到达观景台获得俯瞰视线，失误可后退到转角或回到庭院继续交战。路线不是另一个模式，也不改武器、敌人数量和复活规则。

关卡顺序：山门北侧清楚可见的登山口 → 有石阶的起坡 → 竹林转角 → 山腰横切线 → 岔路口。西侧殿堂的前后门和「西山道」门楼提供第二条入口，外侧石径沿山坡折返爬升后接到同一岔路，使玩家可选择不同方向进攻高地。短支路到较低的「观寺台」，能看清庭院和屋面；主路继续折返上升到西侧山脊的第二处观景台，看到寺院屋顶和周边山谷。两处高点的朝寺院方向都保留视线，边缘设可见护栏；路面、人物支撑、AI 寻路、弹道代理使用同一条路线和高度。远景山体继续复用现有地形与植被，不导入高面数模型。
