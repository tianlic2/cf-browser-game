# 战术突击 · Tactical Assault

穿越火线（CrossFire）风格的浏览器第一人称射击游戏。原生 HTML + Three.js，**无构建步骤、无 npm 依赖**，打开网页即可玩。

**▶ 在线试玩：<https://tianlic2.github.io/cf-browser-game/>**

> 建议用桌面版 Chrome / Edge / Safari。进入战场后需要点击画面锁定鼠标指针（按 `Esc` 解锁）。

## 玩法

可选「运输船」「守望之城」「雪地求生」「黑色城镇」四张场景；黑色城镇同时提供独立的团队竞技版和雨夜生化版。团队竞技模式：**先到 40 击杀，或 10 分钟倒计时结束时比分领先**者胜。运输船中你从船尾（+z）出生，敌人从船头（-z）基地持续刷出。雪地求生由用户提供的 GoldSrc `de_survivor_new` 完整转换为团队竞技地图，沿用原双方各 10 个出生点、建筑、雪山/树木场景、烘焙光照、天空盒与碰撞；黑色城镇由用户提供的 GoldSrc `de_blackwidow` 转换，保留原双方各 16 个出生点、巷道建筑、内嵌贴图、烘焙光照、天空盒与碰撞，并针对本游戏人物比例将三轴统一放大至原换算尺寸的 1.2 倍。两张地图原有的爆破目标均不在团队竞技中启用。守望之城当前 X/Z 平面尺寸为源地图的 1.6 倍、Y 高度为 1.04 倍；该地图可使用 3 号背包的巴雷特及凤凰斧，按 3 切近战，按 Q 在巴雷特和凤凰斧之间切换。敌人也只使用巴雷特。

大厅可切换到**经典生化**，进入黑色城镇的独立雨夜版本；团队竞技的黑色城镇仍保留且不受生化天气和道具影响。生化版沿用完整街区几何、可见地面碰撞和原始路线，另有屋顶阻挡的动态降雨、积水、三辆废弃汽车与一个纯场景装饰的配电箱。开局有 15 秒感染倒计时，随后随机产生生化母体；人类守到 3 分钟结束即获胜，幽灵感染所有人类则获胜。佣兵 AI 通过视觉、听觉、短期记忆与队伍共享线索判断危险，并分别承担守点、支援、侦察和殿后职责；它们会错峰换弹、点射、横移、救援、搜索和在防线失守时转点。幽灵同样没有全图透视，通过感知与最后位置记忆追踪目标，并分工正面施压、侧翼包抄、截断退路和攻击孤立/换弹目标。轻量导演以试探、蓄压、爆发、回落四阶段调节战术积极度，不额外刷怪或修改生命值。生化模式 AK 初始弹药为 30/270，其余枪械备用弹药至少翻倍；击杀幽灵会让所有存活人类补充两个备用弹夹，最多补到本局初始备用弹量。所有幽灵有 5000 HP，死亡 3 秒后在幽灵出生点复活，不会因为被击杀而结束回合；普通追击速度为人类基础跑速的 1.05 倍。受击时幽灵会沿命中方向短暂后退并减速，连发击退有上限，墙体和其他角色会挡住后退，之后恢复追击。

- 首页是 CF 风格大厅，左侧四个页签：**开始游戏**（选择地图，调**敌人数量 1~8** 与**难度 简单 / 普通 / 困难**）、**作战手册**（全部键位）、**武器库**（武器数值）、**个人仓库**（四个背包的配装）。后三页只读。对局中也能用 `+` / `-` 实时增减人数。
- 按住 `Tab` 看战绩面板（左右两列是我方·保卫者与敌方·潜伏者）。
- 被击杀后是 3 秒死亡视角（镜头会自动转向击杀者），然后在你方出生点复活并获得 3 秒无敌，期间敌人攻击不会造成伤害。

## 操作

| 按键 | 动作 | 按键 | 动作 |
| --- | --- | --- | --- |
| `W` `A` `S` `D` | 移动（默认奔跑） | `R` | 换弹 |
| `Shift` | 静步潜行（无声） | `1` `2` `3` | 主武器 / 副武器 / 凤凰斧 |
| `Ctrl` | 按住下蹲 | `4` | 投掷物循环（手雷 → 闪光弹 → 烟雾弹） |
| `Space` | 跳跃（支持连跳） | `Q` | 切回上一把武器（与当前武器往返切换） |
| 鼠标左键 | 开火；投掷物按住拉环、松开投出 | `G` | 丢弃手上的主武器 / 副武器 |
| 鼠标右键 / `V` | 巴雷特两级变倍开镜；凤凰斧重击；炫金雷神枪托攻击（`V` 只负责开镜） | `B` | 背包面板 |
| `+` / `-` | 增减敌人数量 | `Tab` | 战绩面板 |
| `Enter` | 聊天发言 | `Esc` | 打开游戏菜单 |

团队竞技的背包切换按 CF 原版规则限制：**只能在出生点安全区内、且本回合尚未开火时**切换。经典生化则在**僵尸出现前的感染倒计时内**都可按 `B` 换包，不受位置或是否开火影响；感染爆发后锁定背包。鼠标悬停可预览，按 `1/2/3/4` 或点击确认背包，**确认后自动收起面板**（被规则拦下时面板保持打开并给出原因）。

投掷物每条命各一颗：按住左键完成拉环后可以待投，松开甩出，离手才开始引信，随后切回之前的武器。切枪、聊天、失焦会取消未出手的投掷。手雷支持墙面/箱顶反弹、空中爆炸和掩体遮挡；闪光根据视线与朝向生效，烟雾逐渐扩散后消散。物理、伤害、引信和烟雾时长为本项目近似标定。

凤凰斧保留用户提供源模型里的双手、骨骼与完整动作；AK 与三类投掷物也保留各自的素材骨骼动作，其他武器按已接入的视模或握点方案显示。

凤凰斧左键单击播放源模型 `combo_1`，按住会接 `combo_2`；右键播放源模型 `bigshot` 重击。三段动作统一按源速度的 **80%** 播放，命中窗口与攻击间隔同步放慢。轻击身体 35、头部 100，重击身体 90、头部 180；每次攻击有前摇、有效命中窗口和收势，不能隔墙命中。距离按当前场景标定为 **1.5 米**（到实际命中表面），属于近似还原参数，不是官方精确数值。

炫金雷神右键播放源模型独有的 `knife-attack` 枪托动作与原始音效；有效距离同为 **1.5 米**，身体伤害 60、头部伤害 100，不能隔墙命中。源文件只提供动作和音效，不含伤害数据，因此伤害与命中窗口是本项目标定值。

### 聊天

左下角的聊天框与 CF 同位置。**按 `Enter` 打字，再按 `Enter` 发出**（`Esc`解锁鼠标会顺带取消输入）。

打字期间**不会**释放鼠标指针——视角定住、游戏照常跑（也就是说打字的时候真的会被打死）。此时除了输入框，所有按键都不再驱动游戏：`G` 不掉枪、`1/2/3` 不切枪、`R` 不换弹、`+`/`-` 不改人数、`B` 不开背包、`Tab` 不跳焦点。

**线里不是只有你。** 潜伏者会盯着战况说话——你爆头、连杀、被反杀，都有人点评；你打得狠了他们互相提醒「都给我压住」，你也被打死时击杀者会说一句。你发的消息他们会接：问句、挑衅、普通聊天走的是不同的回答口径（只做关键词粗分流，别指望他们真读懂）。冷场的时候也会有人自己找话说。

### 掉落与捡枪

- 普通地图的敌人**随机携带** AK-47 / M4A1，守望之城敌人只携带巴雷特；倒地时枪就掉在它倒下的位置（守望之城不掉枪）。
- 按 `G` 丢下自己的主武器或副武器；**只有对应槽位空着时才会捡起地上那把枪**——手上已经有枪的话，从上面走过去什么也不会发生。想换枪就先丢再捡。
- 捡到的枪（含皮肤）会**一直用到本局结束**（复活拿回来的也是它）；重开一局才恢复成背包里配好的那把。

## 特性

- **多武器系统**：四个背包依次为 AK-47、M4A1-C、巴雷特 M82A1、炫金雷神（35 发弹匣），副武器统一为沙漠之鹰；另有 CFS 2019 凤凰斧与手雷·闪光弹·烟雾弹三件套。AWM 与 USP 已从游戏配装、武器库和加载流程中移除。
- **持枪移动速度**：以凤凰斧奔跑速度为 100%，投掷物 98%、沙漠之鹰 94%、M4 91%、AK 89%、巴雷特 72%；静步、下蹲在各自基础速度上沿用相同倍率，开镜再额外减速。这是按经典 CF 的重量层级做的本项目手感标定，不是原客户端的精确速度表。
- **CS 口径的枪感**：每把枪有一张**逐发弹道表**——连发时枪口沿着固定的轨迹往上爬再左右摆（AK 的 30 发表取自 CS2），停火后按指数 + 线性恢复。后坐**相机全程跟随**，压枪练得出来；巴雷特不开镜射击时，子弹会在准心周围随机散布，开镜后恢复中心落点。
- **准心设置**：对局中按 `Esc` →「设置」可预览并切换经典、紧凑、扩展、点式和圆环准心；选择保存在本机。手持巴雷特时准心隐藏，切换到其他武器后按所选样式恢复。
- **第一人称持枪**：经典 AK、M4A1-C、巴雷特、沙漠之鹰、炫金雷神与凤凰斧均使用已接入的完整或专用视模方案，源素材中存在的动作与音效按事件时间线播放。
- **巴雷特两级变倍开镜**，开火强制退镜并完成拉栓后才能回镜与再次开火。所有主武器、副武器都可穿透木箱，逐箱按枪型衰减伤害；金属、混凝土等障碍仍会挡住子弹。巴雷特还可沿同一弹道连续穿透多名敌人，其他武器命中第一名目标后停止。
- 主武器、副武器、近身武器命中敌人时，准心短暂闪红（约 0.11 秒）；命中与击杀均有提示，打中掩体不会触发。
- **经典 SWAT 人物**：社区 CF SWAT Reborn 模型、原贴图与 50 根骨骼，行走/据枪/受击/倒地由本项目 IK 驱动；头部直接按蒙皮网格判定爆头。AI 使用基于地图凸体碰撞的共享寻路流场。
- **敌人随机配装 + 掉落捡枪**：敌人端的是真枪（不是贴图），型号随机，默认采用经典配色；击杀后枪掉在原地可以捡起来用，自己也能按 `G` 丢枪换枪。
- **武器皮肤就是「换整把模型」**：AK 与 M4 的模型皮肤使用 GLB。游戏里没有即时换皮肤入口——四个背包的默认主武器依次是木托 AK、黑色 M4A1-C、巴雷特 M82A1 和炫金雷神。默认经典枪械在玩家、敌人与地面掉落物之间共用模型；其余未预加载皮肤可回退基础模型配色。
- **双通道视模渲染**：武器与手臂在独立场景里二次绘制，永远不会插进集装箱，开镜时自动隐藏。
- **左上角小地图**（CF 同款雷达）：圆形雷达内按等比例绘制运输船轮廓与集装箱/甲板室，标出你自己的位置与朝向。敌人**只在「你看得见」或「正在交火」时显形**（视野锥 + 真实视线遮挡，枪口火光会短暂暴露位置）——这是雷达，不是透视挂。
- **CF 式切枪动作**：切枪时不播放旧武器的收起动作，而是立即切到目标武器并播放它自己的完整出枪动作；目标武器出枪完成前不能开火。弹药 HUD 与退镜也在切换当帧更新。
- **经典击杀军徽**：准星下方按第 1～6 杀显示六档金色星芒军徽，第 7 杀起显示金色鹰徽；未续上连杀的爆头沿用骷髅图标。短促放大、轻抖、回正后淡出；英文连杀文字和原版男声按各自档位显示与播放。没有全屏冲击波或紫色边缘辉光，黄金爆头仍沿用本作判定。
- **模拟聊天系统**：潜伏者会按你的战绩实时评论（爆头 / 连杀 / 阵亡 / 捡枪各有各的说法），你按 `Enter` 发言他们还会接话；同屏 6 行、每条约 9 秒淡出，与 CF 的左下角位置一致。
- **采样 + 合成的混合音效**：玩家 AK 使用 CF 社区移植包中的原开火、退匣、插匣、拉栓 WAV，保持原速。其他枪械、脚步和界面声音主要来自已有 CC0 录音，奖励音调等由 Web Audio 合成；大厅音乐由用户提供。各来源分别记录在 `audio/CREDITS.txt`，不能统称 CC0。
- **CF 经典英文连杀人声**：采用保卫者（Global Risk）七档录音：Double Kill → Multi Kill → Ultra Kill → Unbreakable → Unbelievable → You Want a Piece of Me? → Come and Get Some!。原速播放，快速连杀只保留最新一档；超过八杀停止连杀播报，保留每次击杀的确认音，HUD 继续累计。移除了系统朗读与电子连杀音阶。语音来源与权利归属单列在 `audio/CREDITS.txt`，不属于 CC0 音效。
- **经典地图素材**：运输船与守望之城使用社区移植的 Source 地图几何、贴图、烘焙光照、出生点和凸体碰撞；雪地求生直接转换用户提供的 GoldSrc BSP v30、内嵌纹理、RGB 光照、天空盒和 GoldSrc v10 场景模型，并为源包缺少的雪花/光晕精灵提供程序化等价效果。守望之城当前按源地图 X/Z 方向 1.6 倍、Y 方向 1.04 倍构建，场景、碰撞、出生点、雷达和 AI 寻路同步调整（旧版 2 倍水平、1.3 倍垂直尺寸的 80%）。海面与枪口火光仍由本项目生成。
- 后续 GoldSrc 地图的导入与空气墙验收统一遵循 [GoldSrc 地图导入规范](docs/goldsrc-map-import.md)，并使用通用碰撞审计脚本检查隐藏 BSP 顶面与画面地面是否一致。

## 经典版视觉

当前包含四张场景、团队竞技与经典生化，以及导入的 SWAT 人物、经典 AK、M4A1-C、巴雷特、沙漠之鹰和相应音效。经典生化复用独立的黑色城镇场景实例并叠加雨夜、积水、废弃汽车与装饰性配电箱；防化服感染者使用单独授权的模型和动作，其转身、追击、攻击衔接由游戏状态机控制。运输船与人物加载失败时有程序化回退；守望之城、雪地求生与黑色城镇加载失败时仍可选择其他地图。经典 AK 第一人称使用导入动作，沙漠之鹰复用统一手臂，其余武器与敌人人物动作由本项目驱动，因此并非原客户端的 1:1 复刻。素材署名、转换方式与使用限制见 [经典素材说明](assets/classic/CREDITS.md)、[生化素材说明](assets/bio/CREDITS.md)及 [音效说明](audio/CREDITS.txt)。

## 本地运行

需要任意静态服务器（ES Module 与 GLB 不能用 `file://` 打开）：

```bash
python3 -m http.server 8000
# 然后打开 http://localhost:8000/
```

`?debug` 会在 `window.__tactical` 上挂一组调试钩子（切枪、冻结敌人、定格换弹姿势、读取画面状态等）。

## 技术说明

- Three.js 固定在 `0.160.0`，**已本地化到 `vendor/three/`**，由 `index.html` 的 import map 指向本地，不依赖任何 CDN。
- 武器手感（逐发弹道表、恢复曲线、开镜倍率与灵敏度、刀的轻重击）移植自
  [counter-strike-in-browser](https://github.com/StarKnightt/counter-strike-in-browser)（MIT License，Copyright (c) 2026 StarKnightt），
  使用其数值和部分既有资产；新增 CF 社区素材的权利归属单列，不能视为本项目自有。
- **音效素材**：除 CF AK 与连杀语音外，既有枪声/换弹/脚步等录音取自该参考项目收录的 CC0 录音（Freesound）；
  收枪/出枪、空枪干击、开镜/退镜与页面交互声是我们自己从 Freesound 的 CC0
  录音里剪的（**Kenney UI Audio 已整体下线，一声都不剩**）；大厅背景音乐为用户提供的素材。
  逐文件署名见 [`audio/CREDITS.txt`](audio/CREDITS.txt)。
- 所有资源路径都是**相对文档**的（`./…`），因此既能本地跑，也能作为 GitHub Pages 的**项目页**（站点根在 `/<仓库名>/`）跑。
- 材质与几何为程序化生成或本地 GLB，无外部资源依赖。
- 更多实现细节与踩过的坑见 [`AGENTS.md`](AGENTS.md)，视觉规范见 [`DESIGN.md`](DESIGN.md)。
